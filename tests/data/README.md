# Записи для тестов

Три голосовых сообщения, какими их присылает Telegram: OGG с Opus внутри, один канал, 48 кГц.
Их слушает `tests/test_voice_e2e.py`: бот скачивает файл, декодирует и отдаёт настоящей модели Vosk.

| Файл | Что сказано |
| --- | --- |
| `timer.ogg` | «поставь таймер на пять минут» |
| `tasks.ogg` | «добавь задачу купить молоко» |
| `shutdown.ogg` | «выключи компьютер» |

Это синтезированная речь (нейроголос Piper «Ирина», тот же, что есть в каталоге голосов программы), а не записи людей.
Получены так: фраза озвучена через sherpa-onnx, затем

    ffmpeg -i фраза.wav -ac 1 -ar 48000 -c:a libopus -b:a 24k -application voip фраза.ogg
